# Selyra — primera maqueta web

Esta carpeta contiene una primera página de presentación para `artselyra.com`, hecha con HTML, CSS y JavaScript.

## Archivos
- `index.html`: contenido y estructura de la web.
- `styles.css`: diseño adaptable a móvil y ordenador.
- `script.js`: menú móvil y año automático.

## Antes de publicarla
1. Sustituye las ilustraciones provisionales creadas con CSS por fotografías reales de tus cuadros.
2. Confirma el correo de contacto que quieres mostrar.
3. Añade tus redes sociales reales.
4. Añade páginas legales adecuadas para tu actividad (aviso legal, privacidad, cookies y condiciones de venta cuando haya ventas). No publiques textos legales genéricos sin revisarlos.
5. Para vender obras, necesitaremos integrar un sistema de pago y gestionar pedidos, envíos, impuestos y devoluciones.

## Vista previa en tu Mac
1. Descomprime el ZIP.
2. Abre la carpeta `artselyra_web_v1`.
3. Haz doble clic en `index.html`; se abrirá en tu navegador.

## Publicación y dominio
Este ZIP todavía NO está publicado y no cambia nada en GoDaddy.
Para publicarlo sin Shopify ni Etsy, podemos usar GitHub Pages para esta web estática. Después se conecta el dominio en GoDaddy siguiendo los valores DNS que GitHub indique para el repositorio.
**No borres ni cambies los registros MX del correo profesional.** Para conectar el dominio se añadirán o ajustarán únicamente los registros web necesarios, conservando el correo.
